# 🏥 MedConnect

> A cross-platform clinic and medical center management system — mobile & web.

---

## 📱 Overview

MedConnect is a comprehensive healthcare management solution built with Flutter, supporting both mobile and web platforms. Designed for clinics and medical centers to streamline appointments, patient management, and daily operations.

---

## ✨ Features

- 📅 Appointment scheduling and management
- 👨‍⚕️ Doctor and staff profiles
- 🧑‍🤝‍🧑 Patient registration and records
- 📊 Admin dashboard with statistics
- 🌐 Web + Mobile support from a single codebase
- 🔐 Role-based authentication (Admin, Doctor, Patient)
- 🔔 Appointment reminders and notifications

---

## 🛠️ Tech Stack

| Technology | Usage |
|---|---|
| Flutter | Cross-platform (Mobile + Web) |
| Dart | Programming language |
| Firebase | Auth & Firestore database |
| REST APIs | Backend integration |
| Provider / Riverpod | State management |
| Clean Architecture | Scalable project structure |

## 🚀 Getting Started

### Prerequisites
- Flutter SDK >= 3.0.0
- Dart >= 3.0.0

### Installation

```bash
# Clone the repository
git clone https://github.com/IbraheemKayed/medconnect.git

# Navigate to project directory
cd medconnect

# Install dependencies
flutter pub get

# Run on mobile
flutter run

# Run on web
flutter run -d chrome
```
